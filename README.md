### **Q1. Velocity and Iteration Forecast (20 pts)**

You’ll calculate Agile velocity and forecast how many iterations are needed to complete a backlog.
Tasks include:

* Computing remaining iterations after the 1st iteration.
* Recalculating velocity after the 2nd iteration (only count fully completed stories).
* Estimating how many total iterations are still required.

---

### **Q2. Burndown Chart Analysis (20 pts)**

Using a burndown chart (44 points over 20 days), analyze progress.
Tasks include:

* Determining if the team is ahead or behind schedule.
* Projecting total days needed at the current burn rate.
* Calculating the required daily burn to finish on time.
* Suggesting two ways to improve progress.

---

### **Q3. User Story Estimation and Splitting (15 pts)**

Given a large story (“A user can manage job postings”), break it into smaller ones.
Tasks include:

* Splitting into **three smaller user stories** using the **AND-rule**.
* Assigning **story points** (e.g., 2, 3, 5) with justifications.
* You may use **JIRA** for this part.

---

### **Q4. Planning and Team Coordination (15 pts)**

A stakeholder wants to add more developers to speed up the project.
Tasks include:

* Explaining why adding people may **not shorten the timeline** (e.g., communication overhead).
* Suggesting **two alternative Agile planning approaches**.

---

### **Q5. Git Collaboration and Workflow (30 pts)**

Hands-on Git practice demonstrating proper branching, collaboration, and merging.
Steps:

1. Create a local repo (`git init`) and a `README.md`.
2. Create and switch to a branch `feature/add-summary`.
3. Add a `summary.txt` on Agile velocity and burndown charts.
4. Push to GitHub and **add a collaborator**.
5. Collaborator adds a `peer_note.txt` file on a new branch (`peer-feedback`).
6. Pull and merge their branch locally.
7. Include **screenshots** showing all commands and GitHub activity.
